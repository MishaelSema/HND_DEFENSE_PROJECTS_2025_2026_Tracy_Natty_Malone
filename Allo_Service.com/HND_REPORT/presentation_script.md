## SLIDE 3: Introduction (1 minute)

"Yaoundé, the capital city of Cameroon, has a population of approximately 2.4 million people. Finding reliable local service providers such as plumbers, electricians, cleaners, or tutors has traditionally been challenging.

Residents rely on personal recommendations or trial-and-error approaches, which present several problems: there is no way to verify if a provider is reliable, there are no standardized prices, and there is no protection when making payments.

My project, Allo Service, is a web-based platform designed to solve these problems by connecting people who need help with people who know how to get it done."

---

## SLIDE 4: Problem Statement (30 seconds)

"Let me highlight the key problems this project addresses. First, difficulty in verifying provider reliability. Second, lack of standardized pricing where providers charge arbitrary rates. Third, payment security concerns - clients risk losing money if providers don't deliver. Fourth, inefficient booking coordination through phone calls. Fifth, lack of accountability with no review system. And finally, geographic dispersion making providers hard to discover."

---

## SLIDE 5: Objectives (30 seconds)

"The main objective of this project is to design and implement a web-based local services booking system that connects clients with qualified service providers in Yaoundé while ensuring trust, security, and efficiency.

The specific objectives include: developing a platform that connects clients with service providers, implementing trust and security mechanisms, designing an escrow payment system, developing KYC verification processes, and integrating mobile money functionality - which is essential for Cameroonian users."

---

## SLIDE 6: Proposed Solution (1 minute)

"The Allo Service platform includes several key features. Users can register as clients or service providers. Providers have detailed profiles showing their online or offline status, pricing, and ratings.

The system supports multiple service categories including plumbing, electrical work, cleaning, tutoring, and more. The booking system manages the complete lifecycle from request to completion.

Most importantly, we implemented an escrow payment system where client funds are held securely until service completion is confirmed. We also added KYC verification requiring ID documents and selfies to build trust in the platform."

---

## SLIDE 7: Materials Used (30 seconds)

"For this project, I used PHP 8.x as the server-side programming language with MySQL 8.x for the database. The web server is Apache, and the frontend uses HTML5, CSS3, and JavaScript with custom styling and Font Awesome icons for visual elements.

The development was done using Visual Studio Code as the code editor, phpMyAdmin for database management, and the WAMP server environment. All technologies used are open-source and freely available.

After development, the project was deployed to a live hosting environment. The application is currently accessible online at http://alloservice.42web.io/ where it can be tested and demonstrated in real-time."

---

## SLIDE 8: Methodology (1 minute)

"This project followed the Agile Scrum methodology with iterative development through sprints. The system architecture follows the Model-View-Controller pattern for clean code organization and maintainability.

The database was designed using Entity-Relationship diagrams with proper normalization. Over the 6-month development period, we had 6 sprints: Requirements and Planning, Database and Authentication, Service Listings and Profiles, Booking and Payment System, KYC and Wallet System, and finally Testing and Deployment."

---

## SLIDE 9: Key Features & Security (1 minute)

"Let me highlight some key features implemented in the system. The online and offline status indicator helps clients know which providers are currently available. Contact information is protected and only shared after booking confirmation.

The report button remains active even when providers are offline - this is important for fraud protection. The escrow payment flow ensures client funds are safe until they confirm service completion.

For security, all passwords are hashed using bcrypt, we use prepared statements to prevent SQL injection, all inputs are validated, and we implemented role-based access control for clients, providers, and administrators."

---

## SLIDE 10: Conclusion (30 seconds)

"In conclusion, I successfully developed a functional local services booking system for Yaoundé, Cameroon. The platform implements trust mechanisms through KYC verification and escrow payments, addresses the mobile money preferences of Cameroonian users, and provides a comprehensive admin panel for platform management.

This project contributes to the digital transformation of Cameroon's service economy and provides a scalable solution for local service marketplace operations.

For future development, I recommend adding native mobile applications, integrating directly with MTN and Orange mobile money APIs, implementing real-time chat, and adding map-based service search.

Thank you for your attention. I am now ready to take your questions."
